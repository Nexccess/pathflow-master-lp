# 11B-Integration

## Start Gate
11B starts only from an Approved Creative Package. Violet Reference Case #01 is the first reference input.

## Pipeline
Approved Creative Package
→ independent 5-question hearing UI
→ answer capture
→ answer processing
→ result generation
→ store inquiry handoff
→ DB / Tracking
→ FUNCTION_TESTED
→ BROWSER_TESTED
→ MOBILE_TESTED
→ FULL_USER_FLOW_TESTED
→ TRACKING_CONFIRMED
→ PRODUCT_COMPLETE

## Creative Lock
11B must not modify Creative-owned fields without returning the package to 11A for revision and re-approval:
- layout
- typography
- color
- images
- section order
- copy
- Information Priority
- Message Strategy
- Visual Direction

## Standard Product Scope
Standard scope is AI first reception: organize the visitor's preferences and connect them to a store inquiry.
Reservation / LINE / Calendar / Spreadsheet / advanced analytics remain optional unless separately approved.

## Functional Reuse
Existing Path-Flow master assets such as diagnose, reception, save-result, and track should be reused where compatible rather than rebuilt from zero.

## Completion Rule
Code Exists != Product Complete.
Deploy Success != Product Complete.
PRODUCT_COMPLETE != Sales Ready.

## Final Connection
11A-Production × 11B-Integration = Path-Flow mass-production E2E.
