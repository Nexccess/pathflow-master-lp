# LP Generator Rule v0.1

Status: DRAFT_FOR_RULE_VALIDATION
Inputs:
- Store Intelligence v1.0
- Design / Marketing Interpretation output
- Creative Concept output
- Visual Direction output
- Production Rule v0.2
- Category Profile

Output:
- rule-driven LP draft
- evidence trace map
- section contract
- CTA/diagnosis contract

## Purpose
Generate a commercially presentable, store-specific LP draft that follows the strategic and visual contracts without turning into a fixed template or a scratch-built one-off.

## Core Principle
The generator may vary presentation, but it may not violate the upstream strategic contract or Production Rule.

## Required LP Functions
Every LP must:
1. Make the store-specific customer problem or desire visible.
2. Make the primary Creative Concept understandable.
3. Show at least one meaningful Future State Representation.
4. Show evidence-backed reason(s) to choose the store.
5. Include Customer Voice or another valid evidence mechanism.
6. Include meaningful Visual Proof appropriate to the category.
7. Lead naturally to Path-Flow diagnosis.
8. Preserve mobile-first usability.

## Section Logic
Section order is Controlled Layer, not Fixed Layer.

The generator selects order according to Customer Journey Emphasis.

Beauty examples:
- anxiety → reassurance → clarity
- uncertainty → clarity → confidence

Possible section roles:
- Hero / promise
- Problem / desire recognition
- Future State visual
- Why this store
- Store values / fit logic
- Customer Voice
- Visual Proof / experience
- Service/options
- Diagnosis entry
- Store information

The same exact section order is not required across stores.

## Visual Rhythm — Beauty Profile
For Beauty category:
- Do not allow 3 consecutive text-dominant sections.
- Introduce meaningful visual change approximately every 2–3 mobile viewports.
- Use at least 3 distinct visual roles across the full LP, e.g. Future State, Store Proof, Customer Voice, Experience, Service choice.
- Do not repeat the same card presentation for 3 or more consecutive sections.
- At least one section must be visually aspirational, not merely explanatory.

## Future State Rule
The LP must visibly implement the upstream Future State Contract.

The implementation may vary:
- style gallery
- texture/result imagery
- lifestyle scene
- consultation experience
- atmosphere
- other category-appropriate visual proof

Unsupported before/after claims are prohibited.

## Evidence Rule
Major store-specific messages require traceability.

For each key claim, maintain:
Claim → Evidence ID(s) → Interpretation → LP Expression.

The visible LP does not need to expose the internal evidence ID, but the draft package must retain it.

## Customer Voice Rule
Customer Voice may be presented as:
- short evidence-backed review summaries
- recurring-theme summaries
- structured review cards

Do not fabricate names, exact quotations, ratings, ages, or attributes that are not in evidence.

When only aggregated legacy evidence exists, label visible content conservatively as review tendency / summary rather than pretending it is a verbatim individual review.

## CTA / Diagnosis Rule
Primary CTA role is fixed:
"希望を整理する（無料・5問）" or approved category equivalent.

The LP must clarify why the diagnosis exists according to the Creative Concept.

Examples:
- girasol: organize current concerns, things to avoid, and desired finish before consultation.
- Lumi: organize desired impression and uncertainty before discussing suitable direction.

CTA must be visible but non-obstructive.

## Mobile Rule
Hard requirements:
- no horizontal scroll
- no clipped text
- body text readable without zoom
- tap targets adequate
- fixed/sticky CTA does not materially cover content
- image crop remains meaningful
- section hierarchy remains understandable in one-column mobile flow

## Asset Rule
If commercial usage status is NOT_CONFIRMED:
- do not mark the final production package as commercial-ready using that asset.
- validation drafts may use generated/licensed placeholders or visual-role placeholders.
- record asset source and status.

## Store Specificity Rule
The LP must visibly express:
- primary Creative Concept,
- reason to choose,
- Customer Voice or Evidence Connection,
- at least one store-specific Controlled/Free visual or information decision.

A category-generic LP with only name/logo replacement is REJECTED.

## Free Creative Layer
The generator may freely choose within upstream direction:
- exact composition
- exact spacing
- decorative treatment
- image cropping
- local section styling
- micro-layout
- final headline expression, provided it remains inside Message Territory and Evidence/Claim Safety
